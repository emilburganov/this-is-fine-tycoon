# Всё нормально · тайкун

Кликер-тайкун по мему **This is Fine**, собранный под русский интернет: хрущёвка, Zoom-планёрка, МКАД, семейный чат и донат через СБП.

Собака пьёт чай, пока всё горит, и говорит «всё нормально». Валюта — **норм**. Стек: **Laravel 13 + Vue 3 + SQLite**. SVG свой, это оммаж, не кадр комикса KC Green.

## Как запустить

Нужны PHP 8.3+, Composer, Node 20+, SQLite.

```bash
git clone <repo>
cd this-is-fine-tycoon
composer install
cp .env.example .env
php artisan key:generate
touch database/database.sqlite
php artisan migrate
npm install
npm run build
php artisan serve
```

Открой [http://127.0.0.1:8000](http://127.0.0.1:8000).

Для горячей пересборки фронта: в одном терминале `php artisan serve`, в другом `npm run dev`.

Тесты экономики: `php artisan test`.

## Core loop

1. Кликай по собаке и кружке — это **глоток чая**, главный экшен.
2. Получаешь **норм** — валюту спокойного отрицания («жиза, держимся»).
3. Покупаешь улучшения, открываешь этапы, ловишь события.
4. Чем выше **жар**, тем больше норма, но чаще кризисы вроде УК и звонка мамы.
5. Прогресс пишется в SQLite и переживает перезагрузку (cookie + `localStorage`).

Это не «кнопка и число»: есть сцена, комбо, криты, idle, сторис, протечка от соседей и витрина доната.

## Сеттинг и этапы

Огонь — топливо мема. Если соседи сверху затопили, idle останавливается, пока не включишь чайник.

| Этап | Когда открывается | Что меняется |
|---|---|---|
| Кухня в хрущёвке | старт | чайник, проводка, соседи |
| Планёрка в Zoom | 60 норма за жизнь | камера выключена, открываются сторис |
| Пробки на МКАД | 280 | городской фон, мерч на WB |
| Залетело в рекомендации | 1 200 | семейный чат и хайп |
| На орбите тоже норм | 5 000 | космос, финальный фон |

## Что сделано

Маленькая игра, не страница с кнопкой:

- мем **This is Fine**, тон под русский рынок: хрущёвка, Zoom, МКАД, семейный чат, СБП;
- ресурс **норм**, клик по собаке/кружке даёт ресурс;
- 7 улучшений, из них 4 меняют механику (idle, комбо, криты, сторис);
- 5 событий: бонус, кризис, затопление, звонок мамы, кот;
- 5 этапов развития;
- прогресс в SQLite переживает перезагрузку;
- 4 идеи монетизации без реальной оплаты;
- desktop и mobile.

## Как устроена логика

Сервер считает всё в `App\Services\GameEngine`. Клиент только рисует и батчит клики (~каждые 380 мс), чтобы не долбить API.

**Глоток** = `1 + уровень кружки`, затем множители:

- жар: `1 + heat/250`
- боевой пропуск «Норм+»: `×1.15`
- семейный чат / сторис: `×3`
- ролик VK: `×2`
- паника «мама позвонила»: `×0.5`
- затопили: `×0.3` и idle = 0

Цены растут экспоненциально (`base * mult^level`), чтобы ранние покупки были быстрыми, а поздние — осмысленными.

### Улучшения

Минимум 5, здесь 7. Помеченные «механика» меняют правила, а не только число.

| Улучшение | Эффект |
|---|---|
| Кружка из Fix Price | +1 норм за глоток |
| **Кофемашина с ресепшена** | появляется доход без кликов |
| **Нервный глоток** | быстрые клики копят комбо до ×5 |
| **Двойной с заправки** | шанс крита ×5 |
| Огнетушитель с Авито | кризисы забирают меньше норма |
| **Сторис «у нас уют»** | новое действие на 20 сек ×3 |
| Футболки на WB | второй idle-поток |

### События

Пишутся в `game_events`. Триггер: пауза ~18 сек + пачка кликов, шанс ~22%.

1. **Залетело в семейный чат** — бонус, ×3 на 20 сек.
2. **УК пишет в домовой чат** — кризис, минус % норма (или страховка «Не горит»).
3. **Соседи сверху затопили** — мемный поворот, огонь гаснет.
4. **Мама: «ты как?»** — штраф, слабые глотки, пока не капнешь корвалол.
5. **Дворовый кот** — бонус пачкой норма.

## Где хранятся данные

SQLite, файл `database/database.sqlite`.

- `games` — сейв: норм, жар, этап, апгрейды, баффы, косметика.
- `game_purchases` — покупки улучшений и демо-доната.
- `game_events` — лог событий.

Идентификатор сейва: cookie `fine_save` + заголовок `X-Fine-Save` (дублируется в `localStorage`). Офлайн-idle считается при следующем запросе по `last_tick_at`, максимум 8 часов.

Каталог (цены, этапы, тексты) — в `config/game.php`.

## Монетизация (без реальной оплаты)

Вкладка «Донат» — витрина под российский казуальный рынок. Кнопки сразу выдают эффект и пишут `game_purchases.note = demo_iap`.

1. **Боевой пропуск «Норм+»** — 299 ₽ через СБП, +15% и шляпа. Как в мобилках.
2. **Страховка «Не горит»** — 149 ₽, карта МИР, следующие 3 кризиса без урона.
3. **Набор новичка** — 99 ₽, +150 норма и золотая кружка. Классический пак «ну никак без него».
4. **Ролик VK ×2** — 4 секунды фейковой рекламы, минута ×2. Модель бесплатных игр в Рунете.

Так игра могла бы зарабатывать: пропуск, расходники против бесячих фейлов, дешёвые паки и rewarded-реклама.
