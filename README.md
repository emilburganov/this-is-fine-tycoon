# This is Fine Tycoon

Кликер-тайкун по мему **This is Fine**: жёлтая собака пьёт кофе, пока комната горит, и делает вид, что всё в порядке.

Стек: **Laravel 13 + Vue 3 + SQLite**. Персонаж нарисован своим SVG (это оммаж, не копия комикса KC Green).

## Как запустить

Нужны PHP 8.3+, Composer, Node 20+, SQLite.

```bash
git clone <repo>
cd this-is-fine-tycoon
composer install
cp .env.example .env
php artisan key:generate
touch database/database.sqlite
php artisan migrate
npm install
npm run build
php artisan serve
```

Открой [http://127.0.0.1:8000](http://127.0.0.1:8000).

Для горячей пересборки фронта: в одном терминале `php artisan serve`, в другом `npm run dev`.

Тесты экономики: `php artisan test`.

## Core loop

1. Кликай по собаке / кружке — это **глоток кофе**, главный экшен.
2. Получаешь **файн** — валюту спокойного отрицания.
3. Покупаешь улучшения, открываешь этапы, ловишь события.
4. Чем выше **жар**, тем больше файна, но чаще кризисы.
5. Прогресс пишется в SQLite и переживает перезагрузку (cookie + `localStorage`).

Это не «кнопка и число»: есть сцена, комбо, криты, idle, стрим, пожар который можно случайно потушить, и витрина монетизации.

## Сеттинг и этапы

Мем держит игру: огонь — не баг, а топливо. Если дождь тушит комнату, idle останавливается, пока не подожжёшь заново.

| Этап | Когда открывается | Что меняется |
|---|---|---|
| Кухня в огне | старт | маленькая комната, тост, кофе |
| Стендап в огне | 60 файна за жизнь | офис, можно купить стрим |
| Город в огне | 280 | скайлайн, открывается мерч |
| Мем виралится | 1 200 | интернет-сцена |
| Всё fine во вселенной | 5 000 | космос, финальный фон |

## Экономика

Сервер считает всё в `App\Services\GameEngine`. Клиент только рисует и батчит клики (~каждые 380 мс), чтобы не долбить API.

**Глоток** = `1 + уровень кружки`, затем множители:

- жар: `1 + heat/250`
- Fine Pass: `×1.15`
- вирус / стрим: `×3`
- реклама: `×2`
- паника «это НЕ fine»: `×0.5`
- огонь потух: `×0.3` и idle = 0

Цены растут экспоненциально (`base * mult^level`), чтобы ранние покупки были быстрыми, а поздние — осмысленными.

### Улучшения

Минимум 5, здесь 7. Помеченные «механика» меняют правила, а не только число.

| Улучшение | Эффект |
|---|---|
| Большая кружка | +1 файн за глоток |
| **Кофемашина** | появляется доход без кликов |
| **Нервный глоток** | быстрые клики копят комбо до ×5 |
| **Двойной эспрессо** | шанс крита ×5 |
| Огнетушитель-декор | кризисы забирают меньше файна |
| **Стрим с места пожара** | новое действие «В эфир» на 20 сек ×3 |
| Мерч This is Fine | второй idle-поток |

### События

Пишутся в `game_events`. Триггер: пауза ~18 сек + пачка кликов, шанс ~22%.

1. **Виральный твит** — бонус, ×3 на 20 сек.
2. **Пожарная инспекция** — кризис, минус % файна (или страховка It's Fine+).
3. **Дождь** — мемный поворот, огонь гаснет.
4. **Это НЕ fine** — штраф, слабые глотки, пока не выпьешь копиум.
5. **Кот из соседней квартиры** — бонус пачкой файна.

## Где хранятся данные

SQLite, файл `database/database.sqlite`.

- `games` — сейв: файн, жар, этап, апгрейды, баффы, косметика.
- `game_purchases` — покупки улучшений и демо-IAP.
- `game_events` — лог событий.

Идентификатор сейва: cookie `fine_save` + заголовок `X-Fine-Save` (дублируется в `localStorage`). Офлайн-idle считается при следующем запросе по `last_tick_at`, максимум 8 часов.

Каталог (цены, этапы, тексты) — в `config/game.php`.

## Монетизация (без реальной оплаты)

Вкладка «Монетизация» — витрина, кнопки сразу выдают эффект и пишут `game_purchases.note = demo_iap`.

1. **Fine Pass** — сезонный пропуск, +15% и шляпа. Подписка / battle pass.
2. **It's Fine+** — страховка на 3 кризиса. Skip-fail / consumable.
3. **Набор новичка** — +150 файна и золотая кружка. Starter pack.
4. **Реклама ×2** — 4 секунды фейкового ролика, затем минута ×2. Rewarded ad.

Так игра могла бы зарабатывать: пропуск, расходники против фейлов, паки и реклама.
